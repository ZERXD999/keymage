# KeyMage v2 — MMO Typing

## รันครั้งแรก
```
npm install
npm start
```
เปิด http://localhost:3000 — หน้าต่างเซิร์ฟเวอร์จะแสดงลิงก์สำหรับเพื่อน (เช่น `http://192.168.1.50:3000`)
บน Windows ดับเบิลคลิก `start.bat` ได้เลย

ตรวจสถานะ: `/health` (ผู้เล่นออนไลน์, RAM, event-loop lag)

## ตั้งค่าอีเมลลืมรหัสผ่าน
1. คัดลอก `.env.example` เป็น `.env`
2. ใส่ `SMTP_USER` / `SMTP_PASS` (Gmail ต้องใช้ **App password** ไม่ใช่รหัสผ่านปกติ)
3. ตั้ง `BASE_URL` เป็นที่อยู่ที่เพื่อนเปิดได้จริง — ลิงก์ในอีเมลจะชี้ไปที่นี่
4. รีสตาร์ตเซิร์ฟเวอร์ → ที่หน้าเข้าสู่ระบบกด "ลืมรหัสผ่าน?"

ถ้ายังไม่ตั้ง SMTP ระบบจะ **พิมพ์ลิงก์รีเซ็ตในหน้าต่างเซิร์ฟเวอร์** แทน (ไว้ทดสอบ)

ความปลอดภัย: รหัสผ่านเก็บเป็น scrypt hash · ลิงก์รีเซ็ตใช้ได้ครั้งเดียว 30 นาที เก็บเป็น hash · รีเซ็ตแล้วทุกอุปกรณ์ถูกออกจากระบบ ·
ตอบเหมือนกันไม่ว่าอีเมลมีในระบบหรือไม่ · จำกัดอัตราต่อ IP/อีเมล/บัญชี

## รันเครื่องโน้ตบุ๊คให้ ~60 คน
- เสียบชาร์จ + ตั้ง Power plan เป็น High performance + **ปิด Sleep** (หลับ = ทุกคนหลุด)
- Windows Firewall ถามครั้งแรกให้กด Allow (Private network)
- Wi-Fi ของที่เรียน/ที่บ้านบางแห่งเปิด *client isolation* ทำให้เครื่องอื่นเข้าไม่ได้ → ใช้ Cloudflare Tunnel (`cloudflared tunnel --url http://localhost:3000`) แล้วตั้ง `BASE_URL` เป็น URL ที่ได้ และ `TRUST_PROXY=1`
- ใช้สาย LAN/ไวไฟ 5GHz ของเครื่องโฮสต์ถ้าทำได้ — คอขวดจริงคือเครือข่าย ไม่ใช่ CPU
- หลุดเน็ตไม่เกิน 25 วินาที ผู้เล่นกลับเข้าห้อง/ศึกเดิมได้เอง
- ข้อมูลบัญชีอยู่ที่ `data/db.json` (สำรองไฟล์นี้ไว้)

## กติกาเกมใหม่
- **⚔ โจมตี** ดาเมจ = ความยาวคาถาตาม grapheme × 10 · **💥 ไม้ตาย** ×1.5 (ยาว เสี่ยงโดนล้าง) · **🛡 โล่** กันการโจมตีครั้งถัดไป · **↩ สวนกลับ** ตีกลับตอนมอนสเตอร์โจมตี
- HP บอสโตตามจำนวนคน (+30% ต่อคน) · ยิ่งยากยิ่งได้คะแนนคูณสูง + โบนัสชนะ
- ผู้เล่นที่ล้มยังดูเพื่อนสู้ต่อได้ · ในมือมีคาถาสั้น (≤6 ตัวอักษร) อย่างน้อย 1 ใบเสมอ
- แถบนับถอยหลังบอกว่ามอนสเตอร์จะโจมตีเมื่อไหร่



## ล็อบบี้และภาษาคาถา (UI Reference)
- หน้าล็อบบี้นำเลย์เอาต์จากภาพที่ `docs/ui-reference/` มาเป็น UI ใช้งานจริง: แผงห้องปาร์ตี้, เลือกภาษา 3 แบบ, เลือกอาชีพ 3 ระดับ, การ์ดมอนสเตอร์ 12 ตัว และทำเนียบผู้กล้าด้านขวา; ภาพอ้างอิงแนบไว้ใน ZIP
- ภาษาคาถามี 3 แบบ: `English`, `ไทย`, `ผสม` (สุ่มคำคาถาจากทั้งสองภาษา)
- ดาเมจของคาถาที่จับคู่กันเท่ากันทุกภาษา ส่วนการนับตัวอักษร/แสดงความคืบหน้าใช้ grapheme cluster เพื่อไม่แยกสระและวรรณยุกต์ไทยผิดตำแหน่ง
- มีสายอาชีพ 20 สาย แบ่งเป็นง่าย 4 / ปานกลาง 5 / ยาก 4 / พิเศษ 7 และมอนสเตอร์ 12 ระดับ
- หน้าเลือกมอนสเตอร์แสดงพลังชีวิตและช่วงเวลาโจมตีตามค่าที่ใช้จริงในเกม

## โหมดใช้งาน: โน้ตบุ๊กและ Cloud

โปรเจกต์นี้ใช้โค้ดชุดเดียวกันได้ทั้งสองสภาพแวดล้อม:
- **Laptop / LAN:** รัน `npm start` แล้วให้ผู้เล่นเชื่อมต่อผ่าน IP ภายในเครือข่ายเดียวกัน ตั้ง `BASE_URL` เป็น IP ที่ผู้เล่นเข้าถึงได้
- **Cloud / VPS:** ติดตั้ง Node.js 18 ขึ้นไป แล้วรันด้วย process manager เช่น PM2 หรือใช้บริการ systemd ตั้ง `BASE_URL` เป็น HTTPS URL และตั้งค่า reverse proxy / TLS ให้เรียบร้อย

ข้อจำกัดปัจจุบัน: เป็นเซิร์ฟเวอร์ Node.js process เดียวและเก็บบัญชีใน JSON file จึงเหมาะกับการรันเครื่องเดียว (Laptop หรือ VPS หนึ่งเครื่อง) หากต้องการ scale หลาย instance ต้องย้าย store ไปฐานข้อมูลส่วนกลางและเพิ่ม Socket.IO adapter ก่อน

## ผลทดสอบโหลดล่าสุด

ดูรายละเอียดใน `TEST-REPORT.md` ผลจำลอง 60 / 80 / 100 connections ผ่านในสภาพแวดล้อมทดสอบ โดยไม่มี socket disconnect หรือ application error ในช่วงเก็บข้อมูล 15 วินาทีต่อรอบ ผลนี้เป็น baseline ในเครื่องทดสอบ ไม่ใช่การรับประกันประสิทธิภาพบนโน้ตบุ๊กทุกเครื่องหรือทุกเครือข่าย

คำสั่ง:
```bash
node test/loadtest.js 60 15
node test/loadtest.js 80 15
node test/loadtest.js 100 15
```

## ความปลอดภัยก่อนแจกจ่าย

- อย่าส่งไฟล์ `.env` ให้ผู้อื่น และอย่าอัปโหลดขึ้น Git
- อย่าแจก `data/db.json` เพราะมีข้อมูลบัญชีและ session ของผู้เล่น
- ใน ZIP สำหรับแจกจะมีเฉพาะ `.env.example` และ `data/.gitkeep` เท่านั้น
- หากเคยแชร์ `.env` ที่มี SMTP credentials ไปแล้ว ให้เพิกถอน/สร้าง App Password ใหม่ก่อนเปิดใช้งานจริง


## ระบบคอมโบ (เพิ่มใหม่)
- ร่ายคาถาติดกันโดยไม่โดนตี → คอมโบ +1 ต่อครั้ง · ตัวคูณคะแนน = 1 + 0.05 × (คอมโบ−1) แต่ไม่เกินเพดานของ "คำที่ยากที่สุดในสายคอมโบ"
- ทุกครั้งที่ร่ายสำเร็จ เวลาโจมตีของบอสถูกหน่วงออกไป (ไม่เกิน 1 รอบเต็ม):

| ระดับคำ (ความยาวฐานของคาถา) | เพดานคะแนน | หน่วงเวลาบอส |
|---|---|---|
| ◆ ง่าย (≤ 8 ตัวอักษร) | ×1.2 | +25% ของรอบโจมตี |
| ◆◆ ปานกลาง (9–14) | ×1.4 | +50% |
| ◆◆◆ ยาก (15+) | ×1.6 | รีเซ็ตเต็มรอบ |

- ภาษาไทย/อังกฤษได้ระดับเท่ากัน (วัดจากความยาวฐานเดียวกับดาเมจ)
- โดนตีจริงคอมโบขาด · **โล่ที่กันการโจมตีได้ไม่ทำให้คอมโบขาด** (ให้คุณค่ากับคาถาโล่)
- ปาร์ตี้หลายคนแชร์เวลาบอสร่วมกัน → ปริมาณที่หน่วงถูกหารด้วยจำนวนคนที่ยังสู้อยู่ (ไม่งั้น 8 คนจะล็อกบอสไว้ตลอด)
- **No Damage**: ชนะโดยไม่เสียพลังชีวิตเลย ได้โบนัส +50% ของโบนัสชัยชนะ
- ปรับตัวเลขทั้งหมดได้ที่ `COMBO` ใน `game.js` · ตรวจสมดุล: `npm run balance:combo`, `npm run balance:nodamage`
- เพราะการหน่วงบอสทำให้เกมง่ายขึ้นมาก HP มอนสเตอร์ถูกปรับเพิ่ม (Cyclops ปรับ HP/ดาเมจร่วมกัน) ให้อัตราชนะของผู้เล่นพิมพ์ปานกลางใกล้เคียงเดิม — ดูตารางใน `TEST-REPORT.md`
